# Experiment plan: frozen Part A

The pre-implementation checkpoint is recorded in the run workspace; this page records the actual executable design. Six scenarios × three replicate IDs × 60 known-truth specimens make 1,080 rows. Each cohort uses a lexicographically sorted sample-ID split of 30 train, 10 validation and 20 test, with IDs in [`fixtures/split_manifest.csv`](fixtures/split_manifest.csv). R generator seeds are `20261026+100r` for base phases and `20261027+100r` for ambiguous phases (`r=0,1,2`); R uses Mersenne-Twister/Inversion/Rejection. Python noise uses PCG64 `SeedSequence([20261026, scenario_index, replicate, 0])` and the analytic illustration uses stream 1. Search seeds belong only to Part B.

Base phases are Quartz, Hematite, Kaolinite and Forsterite; ambiguous phases are Quartz, Anatase and Rutile, with the last two chemically identical on the measured analytes. `easy` is the exact full-rank case. `ambiguous` retains exact assays with a singular phase response. `noisy` adds signed, untruncated Gaussian assay error with channel SD `[.010,.008,.003,.006]` in fraction units. `missing_phase` excludes Forsterite from the fitting inventory. `wrong_chemistry` alters the fitted Kaolinite Al2O3 response. `infeasible` scales the assay by 1.2, exceeding exact closed feasibility. All phases, channels, `C_true`, `C_fit` and simulation settings are in [`fixtures/manifest.json`](fixtures/manifest.json). Ideal simCoDaR XRD and XRF outputs are simulated observations, not independent laboratory measurements.

Before B was run, freeze five rowwise methods (`pinv`, `nnls`, `wnnls`, `cls_eq`, `cls_le`) plus SVD/LP diagnostics. The **predeclared held-out comparator** is `cls_eq` for every case except `missing_phase`, which uses `cls_le`. No comparator is selected using held-out mineral error. Record forward replay, assay/mineral RMSE, failure and unsupported counts, closure/unallocated values, timing, and ILR eligibility. Correctness gates are forward error ≤`1e-10`, constrained feasibility error ≤`1e-8`, full-rank easy recovery ≤`1e-6`, exact equivalence assay difference ≤`1e-12`, and zero unexpected failures. These tolerances test implementation, not field accuracy.

Numerical history matters: v1 had 13 SLSQP failures; v2 changed objective scaling and missed an easy-case gate; v3 tightened stopping and passed. v1 has 49/49 references, v2 55/56 because one historical manifest is absent, and current v3 55/55. The 2026-10-26 08:55:02 UTC v3 freeze precedes the 08:56:24 UTC B results. The full run uses Python 3.13.15, NumPy 2.5.2, SciPy 1.18.1, pandas 3.0.5 and pinned public simCoDaR `d9a0b27676a0cb3a4acb300a3f6b2ebc845d205d`. Neither a 3-replicate pilot nor these point estimators support interval coverage, size, power or formal uncertainty calibration claims.

External data admission requires primary source/version/hash and rights, specimen-level join, comparable measurement support and dry basis, mineral wt% rather than volume proxies, treatment of censoring and amorphous/unclassified material, chemistry provenance, error information and a grouped untouched holdout. [The screen](results/dataset_screen.csv) has no admitted cohort, so external validation remains pending.
