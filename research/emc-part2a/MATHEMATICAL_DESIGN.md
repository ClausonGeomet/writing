# Mathematical design: fixed chemistry and feasibility

For specimen `s`, let `a_s` be a `p`-vector of unnormalized assay mass fractions, `m_s` a `k`-vector of whole-sample mineral mass fractions, and nonnegative `C` the `p × k` response matrix. The model is `a_s = C m_s + ε_s`; stacked rows satisfy `A = M Cᵀ + E`. Each response column is tied to named analytes and a declared chemistry source. An elemental mass response follows atom counts times atomic weights divided by formula weight; oxide-equivalent reporting applies the appropriate molar-mass conversion. Assay closure by normalizing `Cm` would change the model to `Cm/(1ᵀCm)` and is not done here.

The baseline `pinv` reports a minimum-norm LS representative; `nnls` minimizes `||Cm-a||²` subject to `m≥0`; `wnnls` minimizes `||W(Cm-a)||²` with diagonal `W_ii=1/σ_i`. Neither NNLS variant imposes mineral closure. `cls_eq` adds `1ᵀm=1` for a complete phase inventory. `cls_le` adds `1ᵀm≤1`; its `u=1−1ᵀm` is unallocated mass, not a known omitted mineral. Analytical covariance `Σ_ε` would require valid uncertainty calibration; singular closed-assay covariance belongs in a contrast space. Optional geological inequalities `Gm≤h` require external evidence and are absent here.

For `C=U D Vᵀ`, singular values characterize algebraic sensitivity. Check the rank of both `C` and `[C;1ᵀ]` using declared tolerances; compute exact feasible LP extrema `min/max m_j` under `Cm=a`, nonnegativity and justified closure. An empty exact set in noisy or infeasible data is not solver failure. A null vector `v` with `Cv=0` and `1ᵀv=0` preserves assay and closure whenever `m+t v` remains nonnegative. For the ambiguous `C=[[1,0,0],[0,1,1]]`, `m=(Q,TU,T(1−U))` and `m′=(Q,T(1−U),TU)` have the same assay `(Q,T)` sample by sample; phase-specific truth differs. Thus even an exact full assay distribution cannot identify the mineral split.

For fixed `C`, `E[ε]=0` gives `E[a]=C E[m]`. If additionally `Cov(m,ε)=0`, `Cov(a)=C Cov(m) Cᵀ+Σ_ε`; otherwise cross-covariance terms remain. A random `C` adds dependence terms. These are population identities, not an inversion recipe. PCA of `A` describes observed variation, whereas SVD of `C` diagnoses the response map.

Compositional distance is reported only when both mineral vectors are strictly positive and closed on the same support: choose `VᵀV=I`, `Vᵀ1=0`, set `ilr(m)=Vᵀ log m`, and compute Euclidean distance in those coordinates. Structural zeros and censored values need a separate observation model; no pseudocount is inserted. Fraction RMSE remains the primary all-row metric. The summary records eligible ILR counts, including zero-eligible groups.
