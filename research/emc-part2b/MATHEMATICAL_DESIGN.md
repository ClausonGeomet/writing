# Mathematical design: allocation, order search and population loss

On a nonnegative assay `a`, set residual `r=a`, mass `m=0` and available whole-sample mass `b=1`. For each mineral `j` in a permutation `π`, allocate

`δ_j = min(b, min_{i:C_ij>0} r_i/C_ij)`, then set `m_j=δ_j`, `r←r−C_:j δ_j` and `b←b−δ_j`. Return `Cm`, original-basis residual `a−Cm`, and `b`. Every measured component required by a phase limits its allocation; an early phase can consume an analyte needed later. Division by small `C_ij` and assay noise make limiting ratios fragile, especially close to zero. Inputs below `−1e-12` have explicit `unsupported_negative_assay` status; only arithmetic excursions within `1e-12` are corrected and recorded. An all-zero response column is invalid. Remaining `b` is unallocated mass, not an identified missing phase. The allocator is chemical bookkeeping, not a reaction path or HSC rule.

For observed training matrix `A` and predicted `Â`, define row loss `L_r=mean[((A−Â)/σ)^2]`, with `σ=1` absent supplied error scales. Let `t_i=max(sd(A_:i),.01)` and sample covariance `S`. Mean loss is `L_μ=mean_i[(mean A_i−mean Â_i)/t_i]^2`; covariance loss is `L_S=mean_ij[(S_A,ij−S_Â,ij)/(t_i t_j)]²`. Marginal histograms use ten bins with edges `−∞,0,1/8,…,1,+∞`; `L_JS` averages natural-log Jensen–Shannon divergence over channels. `JS(P,Q)=½ KL(P||(P+Q)/2)+½ KL(Q||(P+Q)/2)`, with zero terms defined as zero. The row objective is `L_r`; the distribution objective is `L_r+L_μ+L_S+L_JS`. These unit auxiliary weights are a fixed sensitivity choice, not a likelihood. Training-derived scales are reused on validation/test. Covariance compares some dependence, yet marginal JS does not specify the full joint distribution.

One global order is fit to 30 training assays without mineral truth; it is applied unchanged to validation and 20 test assays. Exhaustive search scores all permutations (at most 24 here); fixed uses lexical order; greedy uses adjacent improving swaps; beam retains two prefixes ranked by lexical completion; random samples with replacement; GA uses six candidates, two elites, order crossover and 0.3 swap mutation across four generations. The latter four search methods have a cap of 24 proposals; duplicate candidates are cached, so actual evaluations differ. GA uses PCG64 seeds 101, 102 and 103. Objective ties within `1e-12` break lexicographically. No finite stochastic search guarantees the global optimum, while exhaustive solves only this tiny finite order catalogue, not mineral inference.

The exact assay counterexample remains `C=[[1,0,0],[0,1,1]]`: changing the Anatase/Rutile partition leaves assays unchanged. Row, moments, covariance and even full distribution losses are invariant to such a swap. Phase-specific measurements or justified geological constraints are needed to identify it. ILR distance is meaningful only on strictly positive common support and is not used as a fitted loss here. No algorithm returns uncertainty intervals.
