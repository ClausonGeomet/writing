# Identifiability and prior sensitivity

For fixed C and observation a=Cm+ε, a feasible direction v with Cv=0 and 1ᵀv=0 (if closure holds) cannot be distinguished by bulk assays. In the quartz–anatase–rutile witness C=((1,0,0),(0,1,1)), a=(3/5,2/5), every m=(3/5,t,2/5−t), 0≤t≤2/5, has the same assay and closure. v=(0,1,−1). Even the complete assay distribution and its moments cannot recover this partition if the same assay-equivalent shifts occur. A phase-specific measurement Hm can remove the ambiguity only if the stacked [C;H] has no remaining feasible null direction. Near collinearity creates weak identification; inspect singular values of appropriately error-weighted C on the closure tangent, local bounds, and sensitivity to C, noise and prior changes. Rank alone does not quantify useful precision.

A prior can select a point in the null class, but selection is prior-driven. For center μ=(3/5,u,2/5−u) and λ||m−μ||²/2 with λ>0, exact fit chooses t=u for any strength λ; λ=0 leaves all t feasible. Hand-chosen truth t=1/10 and wrong u=3/10 produce identical assays with different mineral errors. These are arithmetic illustrations, not observed mineral accuracy. In a weakly measured scalar direction with assay information h and estimate y, Gaussian precision τ yields interior estimate (hy+τu)/(h+τ). For h=1,y=.1,u=.3, τ=1/9 yields .12 and τ=9 yields .28; with correct u=.1 both yield .1. At h=0 every τ>0 picks u. Strength thus changes sensitivity but cannot manufacture assay information.

Under exact closure, abundance covariance has 1 in its nullspace. Tangent regularization avoids pretending it has an ambient inverse. An empirically estimated prior covariance from few calibration samples is uncertain; posterior predictive uncertainty must include both population variation and estimated-parameter uncertainty, plus QXRD error. A unique MAP from a positive-definite penalty is not identified by the assay. If chemistry C varies, mass and chemistry changes can compensate each other; independently measured standards and common chemistry uncertainty treatment are necessary. Observed assay covariance alone cannot uniquely invert abundance covariance through a nontrivial nullspace.

Support restrictions can remove a feasible direction, but a wrong absent-phase assertion can force the wrong allocation while fitting assays exactly. Nondetections need their measurement/censoring model. Domain classification learned from target assays is uncertain; using true held-out domains is an oracle diagnostic only. Apparent prior benefit under leaked labels or duplicated QXRD evidence is invalid.

Order adds no identifiability under free per-sample fractions: all permutations attain the same physical masses in P. Restricting to shared cohort fractions, prefix constraints, order-dependent chemistry or physical support rules may change attainable sets, but each change needs a geological mechanism and a comparator with the same information. Geological formation order is distinct from computational subtraction order. A fair held-out study must measure phase error against independent mineral truth and assess assay fit, support errors and failure rates separately. This has not been done here.
